# 典型页面（设计任何界面前，先来这里看一眼）

> **用法像设计师翻已有界面找可复用的架子：接到任何页面设计任务，动手前先扫下方索引，判断要做的页和哪个典型页面结构相近。**
> 比对结论三态：① **整体同构** → 以该页组方为底、骨架为起点，只替换业务内容；② **局部同构** → 借用对应部位的组方（如只借"出血面板"或"入口卡栅格"）；③ **无相近页** → 按设计模式层自行组织——并在做完后评估是否够通用，够则按文末三步沉淀为新典型页面，让这个库随项目生长。
>
> 这是比设计模式更高一层的参考：模式回答"表单/工具栏怎么做"，典型页面回答"**这一整页怎么组**"。每页给出：何时参考 / 组方拆解 / 易错点 / 可照抄骨架。

## 公开信息设置 —— tab 分区的信息设置 / 展示页

**何时参考**：整页骨架内，用页面级 tab 切分多块内容，每个 tab 是"先展示、点编辑进入修改"的设置/资料页——课程公开信息、个人/项目资料页、对外简介配置页等。

**组方拆解**（每一项的规则在括号内指向的文档，本文件不复述）：

| 部位 | 用什么 | 要点 |
|---|---|---|
| 整页骨架 | 业务组件 `PageFrame` | 组标题 + 导航 + 课程卡 + 面包屑（面包屑首项 = 组标题时返回箭头禁用） |
| 页面标题层 | `<el-tabs class="tabs-page">` | 页面级 tab 充当标题层；与页面顶部间距走「页面级标题与页面顶部之间」锚点；**各 tab 内容必须互斥**（component-interaction.md Tabs 段前置硬规则） |
| 强调横幅 | 渐变切图 + `el-switch` | 条状容器按小卡片档取内边距与 `radius-sm`（foundations 易混场景表）；恒定浅色切图上的文字用 `text-on-light` |
| 内容卡 | `bg-card` + 大卡片档 | 内边距/圆角按大卡片锚点；卡标题用 `title-regular` 字阶 |
| 卡内长文本 | 通栏出血面板 | 完整写法见 foundations.md「卡内通栏出血面板」 |
| 摘要行 + 角标 | `body-sub` + `text-3` + `el-tag--outline` | 「来源」类元信息角标用描边 tag（component-interaction.md Tag 段） |
| 操作区 | `el-button` 主按钮贴左 | 页面级表单操作区主按钮贴左（foundations 主按钮贴边原则）；内容超一屏时操作区流内 `sticky` 吸底（非常驻悬浮条），吸底内衬与负外边距相抵、流内几何不变 |
| 空 tab | `el-empty` + 插画 + `empty-page` | 空态占满整个内容区 = **页面级档**，别误取区块档（档位判据见 component-interaction.md Empty 段） |

**易错点**：空态误取 `empty-block`（占满内容区应为页面级档）；出血面板按"用了 bg-panel 底色"误归面板档（判据是容器体量，嵌套收一档）；吸底做成脱离滚动区的常驻悬浮条。

**可照抄骨架**：`demo/src/components/page/PublicInfoPageDemo.vue`

## 课程工具 —— 分组功能入口集合页

**何时参考**：一页铺开一批功能入口并按语义分组——工具箱页、应用中心、快捷入口墙。

**组方拆解**：

| 部位 | 用什么 | 要点 |
|---|---|---|
| 整页骨架 | 业务组件 `PageFrame` | 同上 |
| 页面标题 | `title-page` 字阶 | 本页无 tab，标题独立成层；上距页面顶部、下距内容均走页面级标题锚点 |
| 功能分组 | `title-module` 字阶 | 组 = 模块：标题下方走模块级标题锚点、组与组走「模块之间」 |
| 分栏 | 源头栅格 `.grid` + `.grid__col-6` | **分栏一律走栅格约定类**（efficiency-guide 栅格系统，已有 @rule）；四列入口卡 = col-6 最小粒度，水槽与换行间距由 `--iflyv-grid-gutter` 提供，页面不写 gap |
| 入口卡 | `bg-card` + `radius-sm` | 小卡片档；图标与文字横向间距走「列表项内子元素·横向」锚点 |

**易错点**：自拼 flex / `el-row` 分栏（栅格规则的反例）；不足一行的组把卡片拉伸铺满（应保持 col-6 留空，同参考页）。

**可照抄骨架**：`demo/src/components/page/CourseToolsPageDemo.vue`

## 课程看板 —— 数据看板页

**何时参考**：整页数据统计/看板——顶部一条核心指标带，下面多张图表卡按模块分组。

**组方拆解**：

| 部位 | 用什么 | 要点 |
|---|---|---|
| 整页骨架 | 业务组件 `PageFrame` | 同上 |
| 标题层 + 主操作 | `.tabs-page` + `el-button type="primary"` 贴右缘 | tab 充当页面标题层；主操作按「主按钮贴边原则」贴容器右缘 |
| KPI 指标带 | `bg-card` 大卡片档 + `number-display-sm` | **单个数字不画图**（display-guide 选型表）；并列次级指标走 `-sm` 数字字阶；一行多指标是卡内条目排布（flex 均布），**不是**页面分栏、不走栅格（col-3 低于 6 列下限） |
| 图表 | 业务组件 `Chart` | 选型按 display-guide 判据（构成→donut ≤5 扇区 / 比大小→bar / 走势→line）；取色/主题重绘/图形风格全在 Chart 源头，页面只传 `type + data` |
| 图表卡分栏 | `.grid` + `.grid__col-12` / `.grid__col-8` | 双卡 12+12、三卡 8+8+8；水槽源头提供 |
| 图表卡 | `bg-panel` + `border-subtle` + `radius-md` | 白底面板叠白内容区靠细描边分界；大卡片档内边距；卡标题 `title-regular`、下方走「常规标题与其下方内容」 |
| 空 tab | `el-empty` + 插画 + `empty-page` | 同「公开信息设置」 |

**易错点**：为单个数字画图（该用数字字阶直接排）；页内手拼 ECharts 重写取色/重绘（一律 `Chart`）；KPI 带硬套栅格（会低于 6 列下限）。

**可照抄骨架**：`demo/src/components/page/CourseDashboardPageDemo.vue`
